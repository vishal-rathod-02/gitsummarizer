
# GitSummarizer

AI-powered GitHub repository summarization and release notes generation.

## Overview

GitSummarizer helps developers understand public GitHub repositories by generating beginner-friendly project overviews, key features, prerequisites, and readable release notes.

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: SQLite or PostgreSQL (team decision pending)
- Repository data: GitHub REST API
- AI summarization: OpenAI or Anthropic (team decision pending)

## Project Structure

- `client/` — frontend application
- `server/` — backend API
- `docs/` — project architecture, API contracts, and setup instructions

## Getting Started

Prerequisites:
- Node.js LTS
- npm
- Git

Setup instructions will be expanded as the frontend and backend are implemented.

## Team Workflow

1. Create a feature branch from `main`.
2. Implement and test the assigned task.
3. Commit your changes and push the branch.
4. Open a pull request targeting `main`.
5. Merge after review and successful testing.
